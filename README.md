# 打造第二大腦
AI 工作記憶

每次思考後，請 AI 整理成 Markdown 存進 Obsidian。下次開新對話或換 AI，讀取同一份筆記，就不用重講。

## 第一次設定
把這段指令交給 AI 助手：

```text
請讀取這份教材：
https://raw.githubusercontent.com/Antoncheng503/inheritclub-second-brain-starter/main/第二大腦建立教學.md
在目前已授權的新資料夾建立 ObsidianVault，並驗證檔案。
請記住：「第二大腦」就是我的 Obsidian 儲存庫。
把實際資料夾位置與這個約定寫進本專案的共用說明。
保留既有設定，不覆寫原本的筆記。
```

能讀網頁與寫檔的 AI 可以協助建立，不必手動下載 ZIP。若只用免費對話工具，依[完整教學](第二大腦建立教學.md)建立資料夾，把 AI 整理的 Markdown 貼進 Obsidian 也可以。

## 每次思考後就說
> 幫我把這份思考整理成 Markdown（.md），存進第二大腦。第二大腦就是我的 Obsidian。保留我的想法、結論和疑問，存好後告訴我檔名與位置。

不能直接寫檔時，請 AI 給完整 Markdown，自己貼進 Obsidian。每次有值得留下的思考就同步。

## 下次換 AI
讓它先讀同一份 Vault 的 `AI共用說明.md`，再讀這次主題相關的筆記。支援本機專案規則的工具可由 `AGENTS.md` 或 `CLAUDE.md` 進入同一份說明；不支援時提供相關文字即可。

各個 AI 不會因為知道「Obsidian」這個名字就自動取得檔案。第一次要選定儲存庫，或提供筆記給它。

## 免費開始

- 這份公開教材免費閱讀，Markdown 就是文字檔。
- [Google 個人帳號 15 GB 空間](https://support.google.com/drive/answer/6374270?hl=zh-Hant)可用於跨電腦同步，與 Gmail、相簿共用。
- 用免費 AI 整理文字後手動存入即可；直接自動讀寫檔案的能力依工具方案與權限而定。

自己的筆記留在自己的資料夾，不會自動傳回這個公開教材庫。公開教材庫只放空白說明與範本。
