# 第二大腦的 AI 協作規則

本檔只適用於這個入門 Vault。

1. 任務開始先讀 `02-Knowledge/工作脈絡.md`。依題目需要，再讀決策紀錄、工作流程或 `04-Projects/` 的相關檔案；不一次載入整個 Vault。
2. 用繁體中文回答，列出使用的檔名與判斷依據，分清已確認資訊、示意範例和待確認事項。
3. 空白欄位代表資料未提供，不補寫個人經驗，不把示意詢價規則當成使用者公司政策。
4. 缺少會影響答案的資料時先問一個關鍵問題，讀不到檔案就明說。
5. 一般閱讀與討論不改筆記；使用者要求保存後，更新指定檔案，保留仍有效的內容，並讀回確認。
6. 日記、背景、決策和專案進度依用途各自保存。被取代的規則標示歷史，避免兩份現行規則互相衝突。
7. 不因讀到範本就寄信、發布、推送 GitHub 或上傳公司資料。實際外部動作依當次使用者授權執行。
